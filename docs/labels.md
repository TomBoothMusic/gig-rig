# Short labels: what each one means

On 28 Nov 2026 the app's wording was cut back to the short labels a sound desk uses, and most
of the on-screen tips were taken away, to leave more room for the controls (Tom's ask). Nothing
about the sound changed, and no preset, song or mixer file changed: only the words on screen.

This page is the key. The older test steps in the README and the other guides were written
before the change and may still use a long name; look it up here. A set-up manual for a new
user (the blank-slate starter) can be built from this page.

## Words used everywhere

| Label | Means |
| --- | --- |
| **HPF** | High-pass filter: the low cut. At 20 Hz it is off. |
| **LPF** | Low-pass filter: the high cut. At 20 kHz it is off. |
| **Freq** | Frequency, where a band sits. Was "... at". |
| **Gain** | Boost or cut of a band, in dB. |
| **Q** | How narrow a band is. A higher number is narrower. Was "width". |
| **LS**, **HS** | Low shelf, high shelf. |
| **B1** to **B4** | The four sweepable bands of the mixer EQ. Was "Band 1" to "Band 4". |
| **LF**, **LMF**, **HMF**, **HF** | The low, low-mid, high-mid and high bands of the Channel EQ. |
| **N1** to **N6** | The six notch filters. "N1 Cut" is how deep notch 1 is. |
| **Thresh** | Threshold. |
| **Makeup** | Make-up gain after a compressor. |
| **Knee** | 0 dB is a hard knee. |
| **SC HPF** | Side-chain high-pass on the bus compressor: it ignores bass below this. Was "Ignore bass below". |
| **Detect** | What the source enhancer measures: RMS or peak. Was "Listens to". |
| **Fdbk** | Feedback of a delay. Was "Repeats". |
| **Sync**, **Div** | A delay follows the tempo, and the note value it plays. Was "Follow tempo" and "Note value". |
| **Glide** | How long the wah or whammy takes to travel heel to toe. Was "Sweep time" and "Bend time". |
| **Pre**, **Post** | Before or after something. On the EQ's RTA row: the sound before or after the EQ. |
| **RTA** | The live picture of the sound behind the EQ curve. |
| **Point** | On the Mixer tab's EQ curve: which of the eight points the Freq, Gain and Q sliders beside the graph belong to. |
| **HP**, **LP**, **L**, **H**, **1** to **4** | The marks on the EQ curve's points: HPF, LPF, low shelf, high shelf and bands B1 to B4. |
| **Flat** | Puts the whole EQ back to no boost or cut. On the Mixer tab it acts on the second press. |
| **FX** | Effects. On the mixer: its four reverbs and delays. |
| **Mon** | A monitor output. |
| **PC** | The program change number Songbook Pro sends to load a song. 0 means none. |
| **DSP** | How much of its time the computer is using for the sound. |
| **GR** | Gain reduction: how much the compressors are turning a channel down. |
| **L**, **R**, **C** | Left, right, centre (a pan of L30 is 30% left). |
| **ENC 5** | The venue knob on the board, and the buttons that stand in for it. |
| **\*** after a preset's name | It has been changed since it was loaded. |

## Record points (Recording tab, and Record on the phone)

| Label | Was | File name says |
| --- | --- | --- |
| **Off** | Nothing | (no file) |
| **Raw input** | The plain socket | `raw` |
| **Post FX** | After its effects | `after effects` |
| **Post looper** | After the looper | `after looper` |
| **Post EQ/comp** | After the looper, with its EQ and compressors | `after channel processing` |

The file names are unchanged, so old and new recordings sit together.

## Recording and soundcheck

| Label | Was |
| --- | --- |
| **Rec mix** | Recording mix |
| **FX returns** | Reverbs and delays (each mixer effect as a file of its own) |
| **Raw inputs** (phone) | Soundcheck copy: a raw copy of every socket, for a virtual soundcheck |
| **Virtual soundcheck** (phone) | Play as a soundcheck |
| **Loop** | Round and round |
| **Replay footwork** | With its loops, kicks and switches |
| **Clear copied**, **Clear all** (phone) | Clear the copied ones, Clear all but the kept |

## Laptop tabs

| Label | Was |
| --- | --- |
| **Source** (Mixer, a channel) | Comes from (after its effects chain) |
| **Rec point** | When recording, record |
| **Direct out** | Direct out for a sound crew |
| **Stereo link** | Stereo (keys, a backing track) |
| **FX sends: Per song (not act)** | Reverb and delay sends: Belong to this song, not the act |
| **Type + settings: Per song (not venue)** | Which reverb or delay this is: Belong to this song, not the venue |
| **HPF (wet)**, **LPF (wet)** | Low cut and high cut on the wet sound |
| **Send EQ: LS, A, B, HS** | Into it: low shelf, band A, band B, high shelf |
| **Sends: Pre-fader** (an output) | Its sends are taken: Before the faders |
| **Tap: Pre all, Post EQ, Post comp** | From where in each channel: before its processing, after its gate and EQ, after its compressors |
| **Pair: Stereo** | Two returns: And the next one |
| **INPUTS**, **FX**, **OUTPUTS** | The headings over the strips |
| **Looper in** (Effects) | Looper hears it as |
| **Monitor** (Effects) | Listen to |
| **Spillover** (Songs) | Delays and reverbs ring out when the sound changes |
| **Auto fade down on: Footswitch, Song load, Input above** (Break music) | Fade down by itself when ... |

The laptop's buttons kept their names, so the click-by-click steps in the guides still work.

| **Sends on faders** | The faders are sending to |

| **Filters** (a mixer effect) | Cuts |
| **Save to song** (a mixer effect) | Keep this effect for this song |

| **Restart: In place / First bar / First note** (Build) | When started again it comes back ... |
| **Stop: Immediate / Loop end** (Build) | When stopped it stops ... |
| **Copy from song**, **Save as new song** (Build) | Start from another song, Save as a new song |
| **DSP peak** (Rig) | Busiest moment |

## What was left alone

- The names of the effects themselves.
- The tabs that are tests or one-off set-up (Device check, Audio, Pedal test, Kick pad, Amp
  capture, Switch screens, Remote screen): their steps are still spelled out.
- Questions that ask before something is lost, and every warning.
- The report (**Copy report**), apart from the settings' new names.
- Pop-up tips that only show when the mouse rests on a control: they take no room.
